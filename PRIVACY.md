# Privacy

Footprint Chess is made for young children. It collects nothing.

## Current version

- No accounts, names, cookies, analytics or advertising.
- Nothing is stored on the device.
- After the page loads, the app makes no network requests. It only loads its own files from the site.

## Hosting

The files are served by GitHub Pages. GitHub records standard request data, such as IP addresses, as the host. See the GitHub Privacy Statement. The app adds no tracking of its own.

## Planned change (stage 5)

Progress will be kept in the browser's local storage on the device. This covers which characters have been met, stickers earned and the chosen theme. Profiles will be pictures, not names.

This data will not be sent anywhere. Clearing the browser's site data deletes it.

This file will be updated when that change is released.
